# Mój licznik dni

A simple iOS application for counting the time elapsed since a selected date.

## Features

- Select a custom start date.
- Display the number of elapsed days.
- Show longer periods in years, months, and days.
- Home Screen widget for quick access to the counter.
- Simple and clean SwiftUI interface.

## Technologies

- Swift
- SwiftUI
- WidgetKit
- App Groups

## Requirements

- macOS with Xcode
- iPhone running a compatible version of iOS

## Getting Started

1. Clone this repository.
2. Open the `.xcodeproj` file in Xcode.
3. Select your iPhone or an iOS Simulator.
4. Build and run the application.
